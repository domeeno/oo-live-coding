# Agario: Modeling enemy capture.

Enemy capture in *procedural* and *object-oriented* programming, from
once very popular game of Agario. 

The example demonstrates how a process can be approached in two different 
paradigms. While the results are the same, the code isn't. It is solved
in two different paradigms - procedural and object-oriented.

Besides syntax, to discover the difference between the two ask yourself
in both paradigms:

1. Who owns the data in `procedural.cpp`, but `oop.cpp`? 
2. Who is allowed to update the state of the `Circle`?
